# Integraciones previstas
WordPress/WooCommerce: empezar con enlaces a la comunidad y guías públicas autorizadas. No habilitar SSO compartido sin revisar el plugin oficial, mapeo de identidades y permisos. El ZIP no instala plugins en la tienda.

Odoo: registrar en proyecto/ticket el enlace de una conversación relevante si sus permisos lo permiten. No sincronizar automáticamente todos los mensajes ni copiar conversaciones privadas a un CRM. Un conector futuro necesita API key con permisos adecuados, auditoría y reglas de idempotencia; no hay tokens ni llamadas reales en esta entrega.

Cursos: enlazar una discusión desde Moodle y probar que solo la audiencia prevista tiene acceso. No hay matrícula ni grupos sincronizados automáticamente.

Membresías/pagos: los grupos y categorías pueden organizar beneficios manuales; Stripe/Flow/Webpay requieren una integración adicional. No se ha activado ni simulado una pasarela como si hubiera cobros reales.

Conservar marca y créditos de Discourse; el servicio operado por Hefesto puede incluir instalación, contenidos, moderación y mantenimiento con alcance acordado. No se incluye facturación, contrato ni SLA.
